# ToDo List Project

A Todo List application built with Vue 3, Vite, TailwindCSS, and Axios.

## Prerequisites

- Node.js (>= 18.0.0)
- npm or yarn package manager

## Project Setup

1. Clone the repository:

```
bash

git clone <repository-url>
cd toDoList
```


2. Install dependencies:

```
bash
npm install
or
yarn install
```


## Development

To run the project in development mode with hot-reload:

```
bash
npm run dev
or
yarn dev
```



The development server will start, and you can access the application at `http://localhost:5173` (or another port if 5173 is in use).

## Build for Production

To build the project for production:

```bash
npm run build
or
yarn build
```


The built files will be generated in the `dist` directory.

## Project Dependencies

- Vue 3 - Progressive JavaScript Framework
- Vite - Next Generation Frontend Tooling
- TailwindCSS - Utility-first CSS Framework
- Axios - Promise based HTTP client
- Vue Router - Official Router for Vue.js

## Development Dependencies

- @vitejs/plugin-vue - Official Vue plugin for Vite
- Autoprefixer - PostCSS plugin for CSS vendor prefixes
- PostCSS - CSS transformation tool
- TailwindCSS - CSS framework
